How the equation works +

The original idea, made explicit

100 × qn

q is the assumed decision score divided by 100.
n is the number of decisions.

The general model multiplies a factor for each decision: d₁ × d₂ × … × dₙ. This calculator holds that factor constant within each scenario so you can isolate the effect of changing it.

Every factor is between 0 and 1, so the combined score falls or stays flat as decisions are added. A higher factor preserves more of the starting score. A larger ratio does not mean the absolute score is growing.

Real decisions are connected, can be revisited, and carry different weights. This simplified index does not estimate success probability, revenue, valuation or return on membership. The starting values are examples, not benchmarks.
