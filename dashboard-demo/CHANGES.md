## Directory (new)
A **Directory** item sits in the sidebar between Advisors and Content library. It is a roster of founders at the member's stage: industry Select + name/company search, dense table (Name, Company, Industry, Location), rows open a member profile. Stage gating is invisible (the sample is Stage 1). No member-to-member messaging in this iteration. Members and selected active prospects share the list and are unlabeled.

## Advisors
Roster is now the **only** browse view (no Cards toggle). The richer card treatment lives on the advisor profile. Search + topic Select unchanged in grammar.

## Benefits
Search + category Select, same control grammar as Advisors / Directory / Library. The previous pill tabs are gone.

## Unchanged
Dashboard, Content library, Profile, mobile proposal, Nexus Partner card under the nav, partner-logo tiles, darkened link color. Dashed **Notes** chips are still prototype-only (hide with `?annotations=0`).
